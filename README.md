# Код Райдо

Музыкальный лендинг. Статический HTML, CSS и JavaScript, сборка не требуется.

- `index.html` — видимый контент, ссылки и формы.
- `site.css` — оформление и мобильные композиции.
- `site.js` — меню, управление анимацией, видео и диалоги.
- `data/site-data.json` — актуальная сводка площадок и текущих работ; при изменении текстов синхронизировать с `index.html`.
- `assets/` — оптимизированные производные обложек проекта. `furina.webp` — обложка «Пока море аплодирует», предоставленная владельцем проекта; остальные обложки и образ дуэта — из исходного репозитория. `shadow-poster.webp` — кадр собственного видеошота из `videos/`.

Хостинг: существующий Vercel-проект `kodraido`. Основной домен: `kodraido.com`; дополнительный адрес: `kodraido.vercel.app`.

Обновление от 5 ноября 2026: новый дизайн, блок мастерской, Фурина, Наруто, NieR: Automata, полные эдиты и идея аниме. Приложение на странице не упоминается. Устаревшие проценты и пресейвы удалены. Видеофайл загружается после нажатия; закрытие и скрытие вкладки останавливают воспроизведение. Ссылки на стриминги сохранены из исходных данных проекта. Существующая форма FormSubmit сохранена; отправка реального письма при проверке не выполнялась.
