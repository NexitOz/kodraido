# Код Райдо — Портал в мир Райдо

Самостоятельный лендинг в `experience/`. Корневая страница репозитория и её Vercel-конфигурация не изменяются.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Контент, ссылки, релизы и пути медиа собраны в `src/content.js`.

## Поведение

- Three.js-сцена загружается после основного интерфейса.
- Переключатель эффектов и `prefers-reduced-motion` отключают непрерывную анимацию.
- Видео запускается только по действию посетителя. Его настоящая аудиодорожка управляет свечением ядра через Web Audio API.
- Диалоги используют нативный `<dialog>`, закрываются клавишей Escape и возвращают фокус.
- При отсутствии WebGL остаётся CSS-композиция и весь основной контент.
